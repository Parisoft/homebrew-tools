This folder is a libdragon install tree WITHOUT the cross-compiler: mips64-elf
GCC is 1.5 GB raw and GitHub caps single files at 100 MB, so it is not shipped
here. Get it from libdragon's own rolling release, which installs into
/opt/libdragon:

    wget https://github.com/DragonMinded/libdragon/releases/download/\
toolchain-continuous-prerelease/gcc-toolchain-mips64-x86_64.deb
    sudo dpkg -i gcc-toolchain-mips64-x86_64.deb

That deb also exports N64_INST=/opt/libdragon itself, so with the deb alone you
need no environment at all - setting N64_GCCPREFIX is only needed because the SDK
here is a separate folder. n64.mk supports the split (N64_GCCPREFIX ?= N64_INST).

Alternatively drop this tree on top of the deb's prefix and keep using the
defaults:  sudo cp -a <this folder>/. /opt/libdragon/
